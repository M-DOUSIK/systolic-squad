## Zero fraction of the NPU layers' input activations (what ZERO_SKIP can skip)

Shipped quantisation: every activation is a ReLU / ReLU6 output stored with zero point -128 (real 0 = q -128), so q == 0 is a mid-range value and the array's zero-skip almost never fires.
